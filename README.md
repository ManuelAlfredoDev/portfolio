# Manuel Alfredo Fierro Duarte — Technical Portfolio

Static portfolio website for Manuel Alfredo Fierro Duarte, an IoT and Automation Developer focused on Python, Node.js, monitoring, data processing, REST APIs, automated testing, and real-time systems.

Live site: [manuelalfredodev.github.io/portfolio](https://manuelalfredodev.github.io/portfolio/)

## Run locally

Open `index.html` in a browser, or serve this folder with a local static HTTP server.

## Public demos

- [Claudia Nueva](https://github.com/ManuelAlfredoDev/claudia-nueva): a safe, simplified public demo with simulated responses and automated tests.
- [SIGOP Demo](https://github.com/ManuelAlfredoDev/sigop-demo): an operational-management prototype with APIs, real-time communication, and simulated MQTT.

## Scope and security

This repository contains only public, demonstrable portfolio content. It contains no external APIs, analytics, credentials, operational data, or private infrastructure details.
